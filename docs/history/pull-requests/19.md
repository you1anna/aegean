## Description

The README workflow diagram used plain rectangles with one text style, and the default Mermaid theme. This change makes the four steps easier to read. The content and the order of the steps do not change.

## What changed

- Each step shows a bold name and a smaller line for the role.
- The automated steps use rounded boxes. The human step uses a pill shape, so the shape shows the human gate as well as the colour.
- A Mermaid `init` directive sets the base theme, font, spacing and curved arrows.
- All arrows use the existing navy stroke (`#56749a`).
- The fills, text colours, `accTitle` and `accDescr` do not change.
