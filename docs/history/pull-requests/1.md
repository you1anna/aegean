## Description

Aegean adds a human-governed delivery workflow, managed Mac installation and isolated CLI verifier. The bootstrap remains gated and draft until native, two-host and lifecycle acceptance is complete.

This revision integrates the coordinator recovery work and addresses the PR review:

- Centralize candidate Git operations, suppress hooks and reject executable filters/diff helpers, candidate config includes and nested Git metadata before host execution.
- Bind spec approval to a published commit and digest. Require separate human authorization for the exact verified candidate before any CI-triggering candidate push.
- Deliver only public requirement feedback to repairs, bound context/review size, freeze run policy and distinguish candidate failures, cancellation and verifier infrastructure faults.
- Fence ownership, reconcile uncertain pushes, serialize cancellation/recovery, retain verifier resource intent and refuse to release ownership until cleanup is confirmed.
- Build installs from clean committed source and validate typed, hashed acceptance reports against all shipped artifacts and the Node executable. The toolchain owns the verifier image; host configuration owns path exclusions.

Follow-up usability review:

- Added repeatable `configure --exclude PATH`, including additive migration that preserves host identity, billing acknowledgement and existing exclusions. Configuration writers use a short atomic lock; excluding `/` now excludes all descendants.
- Local validation for this follow-up: type checking and all 47 tests pass, with zero failures or skips; independent review found no further actionable defect after the root-exclusion correction.
- The separate follow-up assessment is in docs/PR-1-FOLLOWUP-REVIEW.md. The operator selected a bounded CLI pilot first with each Mac qualifying independently; docs/BOUNDED-CLI-SPEC.md is a concrete draft for human review. The proposed pilot, containment, local-approval, revision, lease and routing changes are not implemented by this configuration patch. example-project support follows separately.

Earlier remediation validation on the primary Mac:

- Clean offline dependency installation, type checking and installer/setup script syntax checks passed.
- Mac full `npm test` at `dab0169`: 45 passed, 0 failed or skipped (440.5 seconds). Includes real local-Git coordinator lifecycle/fault fixtures, malicious Git helpers, cancellation, verifier classification/cleanup and release provenance/acceptance rejection controls.
- The first Linux CI run passed 44/45 tests; the direct verifier fixture incorrectly used the macOS `/private` export path. The test-only follow-up gives it a disposable export root, retains all assertions and passes both verifier tests plus type checking locally. Hosted CI for `c7c5a63` (archived CI record) now passes type checking and all 45 tests, with zero failures or skips.
- Test-first regressions reproduced the reviewed failures; a fresh independent review found no additional blocking implementation defects after the fixes.
- The original alleged source-hash mismatch was disproved: the clean original commit and installed source hash match when symlinks use the installer’s representation. Clean-build and artifact provenance still needed strengthening and are included here.

Known release blocker: a native probe confirmed that a detached/session-separated child can keep writing after its parent exits. Process-group cleanup does not contain it. The acceptance contract requires the currently unsatisfied `detached-writer-contained` check on both hosts; ordinary runs and real-project enrolment must remain disabled. The current Builder sandbox also cannot run the actual npm entry point, so general npm/build support is not claimed.

No new release was installed, acceptance state changed, real project enrolled, PR merged or live model called during remediation. secondary Mac acceptance, real cross-host failure exercises, full live human approval/merge/archive and a compatible real pilot remain pending. The control ledger retains full history for uncertain-push ancestry reconciliation; shallow-clone optimization is deferred.
