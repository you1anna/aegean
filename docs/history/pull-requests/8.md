## Description

## What this lets you do

Run `aegean guide` (or `aegean` alone at a terminal) in an enrolled project. The guide asks a question for each step.
You select an answer with the arrow keys or a number. You do not copy a command or a run ID.

Steps that the guide covers: host check, unfinished runs, project check, request (a file, or your editor on a new private file),
run preparation, pilot limits and authorisation, the Scout draft, and the specification review (read, edit, record, approve, cancel).
After the approval, the first choice stops the guide.

## How it works

- `src/cli.ts`: the command switch is now one `dispatch` function. The command line and the guide both call it,
  so the diagnostic log, the host reservation and each gate are the same on both routes.
- `src/domain/guide.ts`: pure choices for each run state. `src/application/guide.ts`: the sequence.
  `src/adapters/terminal.ts`: prompts, a progress line and the editor call. Node standard library only; no new dependency.
- `confirmHumanDecision` is unchanged. The human types each `pilot` and `approve` confirmation.
- The guide refuses a pipe. The skill text tells agents not to operate it.
