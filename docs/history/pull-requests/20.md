## Description

## Problem

`aegean doctor` and the guide reported `pilot-prerequisites: missing builder-isolation prerequisite evidence for this host` with no next step. The operator had to search `docs/OPERATIONS.md` to find `aegean qualify`.

## Change

- **Guide** (`src/domain/guide.ts`): a failed `pilot-prerequisites` check now offers "Qualify this host for this release". The choice runs `aegean qualify`, then the guide checks the host again. The operator selects it; the guide does not run it automatically.
- **Doctor detail** (`src/application/runtime.ts`): the failure detail now ends with `run aegean qualify, then aegean doctor --require prerequisites`. This shows in plain and JSON output.
- **Recovery hint** (`src/application/cli-arguments.ts`): errors about missing or failed prerequisite evidence (for example, from `authorize-pilot`) get the same advice. If an observation fails again, the hint tells the operator to read the operations guide and not to bypass it.
- **Docs** (`docs/OPERATIONS.md`): guide step 1 lists the new fix.

Scope stays small. `subscription-overflow`, `host-exclusions` and `release-acceptance` still have no automatic fix.
