## Description

Aegean now selects explicit model settings for each task and checks the remaining token allowance before each model call. Unknown scope, repairs and both Auditors use the baseline. Smaller Scout and Builder models require policy-bound qualification evidence. The shipped policy contains no qualified smaller-model entries.

Required context must fit in full. Optional source has a deterministic omission record. Builder tool results share a byte allowance. Usage records preserve model identity and provider measurements. Interrupted calls retain their reservations; completed effects settle once without another model call. Strict token caps remain unsupported and are refused. Monitored allowances can overrun during a call.

This PR also completes the required local approval, publication, revision, scoped pilot and recovery paths. It retains the VM-contained Builder, protected verifier, exact human decisions and separate execution permits. Installation and routing activation remain separate operations.

The README and linked guides use plain descriptions of supported work. Model settings, technical decisions and trial evidence have separate references. See [model use](https://github.com/you1anna/aegean/blob/archive/pr-2/docs/MODEL-USAGE.md), [source review](https://github.com/you1anna/aegean/blob/archive/pr-2/docs/MODEL-POLICY-REVIEW.md) and [progress](https://github.com/you1anna/aegean/blob/archive/pr-2/docs/BOUNDED-CLI-PROGRESS.md).
