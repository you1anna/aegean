## Description

## What this change does

The Scout now requests `claude-sonnet-5-5` at high effort. Before this change it requested `claude-sonnet-5` at medium effort.
The operator made this decision after the draft of pilot project run `trial-03`, which named eight record types without fields.

The Scout makes one call for each run, and its draft is the contract for each later stage. Both Auditor tasks and the Builder are unchanged.

## Detail

- `toolchain.json` owns the setting. The policy version is `0.6.0`, so that a run from the earlier setting has a different policy name.
- `minProjectStandard` stays `0.4.0`. A project with standard `0.5.0` needs no edit.
- A run that policy `0.5.0` created is cancel-only on a release with this change.
