## What this lets the user do

- Trust the `project check` preview: it uses the same prompt builder and size limit as the run.

## Weak points found in review, and the correction

| Weak point | Correction |

| A draft entry over 600 characters failed a charged Scout call. | Limits are wider (2,000 characters for each entry). The prompt asks for at most 300. |
| The pause reason after a bad answer was generic. | `responseFault` names the fault class and field names. It never includes model text; a test proves this with a marker string. |

| Version order had two implementations. | `scripts/cli-version.mjs` exports `compareVersions` and `isStableVersion`; the project standard check uses them. |
| `doctor` printed a raw `ENOENT` for an absent acceptance record. | It prints a plain sentence. The check still fails. |
