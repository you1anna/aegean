## What this changes

`aegean guide` (and `aegean` with no arguments at a terminal) now opens with the Aegean mark and the `Λ E G E Λ N` wordmark, taken from the README hero image.

- The mark is 9 rows of Braille cells, 29 columns wide. It was traced from the logo area of `docs/images/aegean.png` with a one-off script (Pillow: crop, luminance threshold 0.26, 2×4 dots per cell). Each cell has a tone class from the image colour: cool blue for the left stroke, sunrise orange for the glowing right edge. The art is a constant in `src/adapters/brand.ts`; the repository has no image or Python dependency.
- Colour follows the terminal (`getColorDepth`): true colour, then 256 colours, then named colours through `styleText`, then plain text. `NO_COLOR` and `TERM=dumb` give plain text. No background colour is set. The tones are mid-range so the mark shows on dark and light themes.
- Below the width of the mark, only the wordmark shows. No banner line is longer than the terminal width.
- Step titles have a dim rule after them. Menu hints are dim and the selected label is bold. The key hint now reads `↑/↓ or a number to move · Enter to select · Ctrl-C to stop`.

The change is in the terminal adapter only. The `GuideUi` port and the guide flow do not change.
