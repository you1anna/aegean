## Summary

`aegean qualify` now ends its result with a list of next steps.

- A pass names the `aegean doctor --require prerequisites` check and `aegean guide`.
- A failed, unknown or uncleaned control names the control, the cause to inspect and the next command to run.
- A thrown qualify failure gets a specific recovery hint.

The logic is a pure function, `qualificationSteps`, in `src/domain/next-steps.ts`. The CLI and the qualification module call it.
