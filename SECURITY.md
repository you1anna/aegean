# Security policy

## Supported versions

Only the latest commit on `main` gets security fixes. Aegean has no versioned
public releases yet.

## Report a vulnerability

Do not open a public issue for a security problem.

1. Open the **Security** tab of this repository.
2. Select **Report a vulnerability**.
3. Describe the problem, the affected commit and the steps that show it.

The report stays private between you and the maintainer.

## Scope

These areas are in scope:

- Builder containment and the protected verifier.
- Approval, ledger and permit controls.
- The installer and the files that it writes.

The maintainer has no response-time commitment. Aegean is a personal project.
